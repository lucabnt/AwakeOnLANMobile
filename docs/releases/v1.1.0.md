# v1.1.0 — Widgets, encrypted backups and refreshed design

First feature release of the personal fork, based on nellogan/AwakeOnLANMobile.

## Added

- Android home-screen widgets and a Quick Settings tile to wake a saved PC.
- On-demand TCP reachability checks with separate PC address/port settings.
- Password-encrypted portable device backup and import (Android 8+).

## Improved

- Header respects system-bar and display-cutout insets, with a 48×48 dp menu touch target.

- Standard local IPv4 broadcast fallback (`255.255.255.255`) shared by the app and shortcuts; explicit destinations preserved.
- Brief toast after successful Wake submission, with blocking alerts reserved for send errors.

- Saved devices appear at startup.
- Refreshed light and dark themes, turquoise accents, compact device cards and accessible touch targets.
- New app icon.
- Keystore-backed encrypted device storage, serialized saves and stricter native validation.
- Bounded, cancellable network scans and updated npm dependencies with security fixes.

## Installation

Choose arm64-v8a for Pixel 9 and most recent Android phones. Android 7+ is required.

This fork uses a personal signing certificate. Updating another distribution may require uninstalling it first, which deletes local devices. Export a backup first when available. Future updates of this fork must use the same certificate.

## Limitations

Wake-on-LAN requires compatible PC and network settings. Packet submission does not confirm boot; an unsuccessful status check does not prove a PC is off. Use a trusted LAN or VPN. Widget/tile use requires unlocking the phone. iOS is not supported by this release.

## Validation

Release preparation: 19 JavaScript tests, 8 dependency regression tests, native C++ security tests and 6 Android widget tests (including local broadcast delivery) passed; TypeScript and lint checks passed with no errors; npm audit reported zero known vulnerabilities. Release APKs built successfully for all four architectures. Light/dark layouts, standalone release startup without Metro, and the header menu touch target in portrait/landscape were checked on a Pixel 9 emulator (QA copy signed with the development key only). Distribution APKs still require the maintainer signature. Complete a final physical-device smoke test of the signed 1.1.0 APK before publication.
