# v1.2.0-rc.3 - Refined Wi-Fi subnet controls

A focused interface refinement for Scan Hosts, based on feedback from RC2.

## Changes since RC2

- Centered **Use current Wi-Fi subnet** directly below the subnet input.
- Replaced the primary accent fill with a neutral secondary-button style, a subtle
  border and text consistent with **Status** in Device List.
- Let the button width follow its label within the available screen width, with
  centered text and a minimum 48 dp touch target.
- Kept **Scan** as the primary action, with subnet selection grouped near its input.

Wi-Fi automations, scan results, diagnostics and backup behavior are unchanged.
This remains an Android prerelease; real-device and background-delivery validation
limits described in RC2 still apply.

## APK preparation - pending before publication

The draft intentionally has no APK attachments yet. Build from this release's target
commit after checking out `feature/wifi-discovery-diagnostics`, with a clean working
tree. The version is already set to `1.2.0-rc.3`, base versionCode `100202`.

1. In Android Studio, open the `android` project and use JDK 17 for Gradle.
2. Choose **Build > Generate Signed App Bundle / APK > APK**, select the existing
   maintainer keystore and build the **release** variant for all four ABIs.
3. Verify every APK with `apksigner verify --verbose --print-certs` and
   `zipalign -c -P 16 4`. Confirm embedded versionName `1.2.0-rc.3` and ABI codes
   ARMv7 `10020201`, ARM64 `10020202`, x86 `10020203`, x86_64 `10020204`.
4. After verifying the signature, name the distribution copies
   `awakeonlanmobile-<abi>-1.2.0-rc.3.apk`, using `armeabi-v7a`, `arm64-v8a`,
   `x86` and `x86_64`. Android Studio may leave `-unsigned` in signed filenames;
   remove it only after checking the signature.
5. Generate `SHA256SUMS.txt` from the four final signed files and attach those five
   files to this draft. Keep old RC2 APKs unchanged; renaming them does not create RC3.
6. Test updating an existing installation without uninstalling, check Scan Hosts in
   light/dark themes and confirm manual subnet entry and Wi-Fi subnet detection.
   Publish this draft as a **prerelease**, keeping stable/latest unchanged.
