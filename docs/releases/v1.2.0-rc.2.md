# v1.2.0-rc.2 - Wi-Fi automations, smarter scans and diagnostics

This release candidate adds Wi-Fi automation, easier device discovery and richer
network diagnostics. It also improves encrypted backup reliability. Android 7+
is required; encrypted backup requires Android 8+.

## New features

- **Wi-Fi automations:** wake a saved PC when the phone connects to a named Wi-Fi
  network, or require an exact SSID as an extra condition on any automation.
  Repeated connection events and brief reconnects are suppressed. Precise location,
  location services and background location access are required where applicable.
- **Smarter discovery:** detect the current Wi-Fi IPv4 subnet and add a discovered
  host through a prefilled device form. The device MAC still needs to be entered.
- **Larger, cancellable scans:** scan up to 1,024 addresses (/22-/32) with at most
  16 concurrent probes and a 30-second limit. Progress and discovered hosts appear
  during scanning, and cancellation/time limits preserve partial results.
- **Advanced diagnostics:** run ten TCP or ICMP probes with individual durations,
  response loss and an average over successful responses. Partial reports remain
  visible when cancelled. Open Status > Advanced diagnostics.
- **Legacy IP recovery:** on Android 7-9 only, a secondary collapsed section can
  look for a unique MAC/IP association and ask before updating addresses. This
  action is hidden on Android 10+ because ARP-table access is restricted.

## Fixes and refinements

- Backup export validates and confirms the password, then encrypts the archive
  before opening the save picker. Success is reported only after writing completes.
- Wi-Fi trigger and SSID-condition fields survive encrypted backup/export/import;
  imported automation rules remain disabled and runtime credentials are excluded.
- Late diagnostic-progress replies no longer replace a completed report.
- Repeated IP recovery requests cannot queue overlapping scans.
- UI and Android resource/compatibility cleanups.

## Validation and remaining limits

33 Jest tests and 29 Android instrumentation tests passed on an Android 15/API 35
emulator. TypeScript, ESLint and dependency regression checks passed. Android Lint
reported no errors; compatibility/deprecation warnings remain. Native C++ tests
cover validation, UDP packets, scan cancellation and deadlines. A 1,024-address TCP
scan took about 6.8 seconds on the emulator's reserved benchmark network; actual
phone and LAN performance varies.

Real-phone testing of wake delivery, battery restrictions/Doze, reboot, VPN and
legacy ARP recovery is still pending. Wi-Fi identity may be unavailable when Android
permissions or location services are disabled; automation then fails closed. A
submitted wake packet does not prove PC startup. This is a prerelease, not a stable
hardware-validated release. iOS remains an unsupported upstream scaffold.

Choose **arm64-v8a** for most current Android phones; other APKs support ARMv7,
x86 and x86_64. APKs must use the existing maintainer certificate for updates.
Embedded version: `1.2.0-rc.2`; ABI versionCodes: `10020101`-`10020104`.
